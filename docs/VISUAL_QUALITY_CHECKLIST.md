# Visual Quality Checklist

- [ ] 60 FPS on a mid-range laptop and current mobile browser.
- [ ] No gameplay rendered with DOM rectangles or CSS animation.
- [ ] Scene uses parallax background, midground, playable terrain, foreground haze, and particles.
- [ ] Camera uses smoothing, dead zone, dynamic zoom, shake, and fade transitions.
- [ ] Hero has anticipation, active, recovery, cancel, hitflash, squash/stretch, and clear silhouettes.
- [ ] Combat has hitstop, knockback, stun, iframes, impact ring, and contextual shake.
- [ ] Enemies expose idle, alert/chase, combat, stun, retreat/death-ready state slots.
- [ ] Palette is biome-owned and never ad hoc per object.
- [ ] UI reads like a premium handheld console overlay, not a web dashboard.
- [ ] Audio layers are split into ambience, music stems, one-shot SFX, and spatial SFX buses before asset lock.
